# 稳连 · 校园网助手 v0.10.0

学生开发的非官方工具，适用于南华大学校园网：保持在线，卡了告诉你为什么、该怎么办。

## v0.10.0 去掉 Node.js 依赖

校园网认证从「C# → PowerShell → Node.js → login.cjs」改为主程序内置的 C# 实现（`PortalClient.cs`、`CampusLogin.cs`），安装包不再携带 node.exe、`login.cjs` 和 `Campus-AutoLogin.ps1`。

- 协议逐条沿用原 `login.cjs`：Cookie 与 CSRF 流程、已在线不重复提交、状态不明确不提交、验证码/改密码/账号拒绝/拨号失败时停止、拒绝跨地址重定向和 POST 重定向、单次请求超时与整体时限、512 KiB 响应上限、从校园网地址（10.14/10.15）发出以绕开 VPN 与加速器隧道。表单编码与 Cookie 解析按浏览器规则实现，含特殊字符的密码提交内容与原版一致。
- 不使用系统代理，不发送 `Expect: 100-continue`；校园网地址不可用时报错，不会退回默认路由。
- 原 PowerShell 登录任务的保护原样保留：同一用户同时只运行一个登录任务；所有登录（手动与自动、任意进程）共用「10 分钟最多 3 次」；学校拒绝后暂停自动提交，直到重新保存账号密码或运营商。`auth-state.json` 格式不变，升级后此前的暂停与计数继续有效。
- 后台监控不再单独计数（原 `recovery-state.json` 不再写入），改为读取上面的共用限额，避免两套计数不一致。
- 密码不再经环境变量传给子进程；后台每次状态检查不再启动 node 进程。实测本机一次状态检查约 70–160 ms（原方式约 330 ms，含启动进程）。
- 删除不再使用的旧版主窗口代码（`MainWindow`、`AccountDialog`、`SwitchControl`）。
- 构建脚本改为带 BOM 的 UTF-8，Windows PowerShell 5.1 也能直接运行 `Build-App.ps1`（原文件在 5.1 下因中文按 GBK 读取而无法解析）。

- 认证页回复按 `JSON.parse` 的严格规则解析（单引号、无引号键、注释、NaN 等一律视为无法识别，不会因此提交账号）；`Set-Cookie` 按原始行读取，逗号不会拆开 Cookie；重复的 `Location` 只取第一个；`Location` 中的反斜杠、制表符按浏览器规则处理；响应短于声明长度视为中断；CSRF 令牌含无法放入请求头的字符时停止。

验证：`tests/Verify-Portal.ps1` 97 项（替代 `portal-client.test.cjs` 与 `Verify-Runner.ps1`，覆盖协议、编码、Cookie、超时、重定向、JSON 与 `Number()` 语义、限频、拉黑、并发互斥、旧版状态文件兼容、日志不含密码），核心检查 `tests/Verify.ps1` 通过。另用 173 个本地场景把原 `login.cjs` 与新实现放在同一假服务器上做差分对比：除超时提示文字、更严格的地址检查和非 ASCII 请求头字节外，请求序列与结果一致，不存在原版不提交而新版提交的情况。在校园网环境下与原 Node 版做只读状态对照，结果一致。

已知差异：重定向地址带用户名（`http://user@host/`）时新版拒绝（原版接受）；请求头中的非 ASCII 字符按收到的原始字节回送（与浏览器一致，原版 POST 时会改写为 UTF-8）；.NET 接受已废弃的折行响应头（原版断开）。

## v0.9.0 界面重做

软件更名为「稳连」，换用新图标（不再使用校徽），界面从 7 个页面精简为 4 个：

- **首页**：先给结论（网络正常 / 需要重新认证 / 网络未连接…），下面是延迟、下载速度、Wi-Fi 信号三项指标；「重新认证」按钮只在需要时出现；「最近发生」把技术日志改写成简短说明。
- **游戏模式**（新）：打游戏时记录宿舍网关、学校服务器延迟和 Wi-Fi 信号，卡的时候点「刚才卡了」，自动判断卡顿更可能来自无线信号弱或切换热点、每分钟一次的 Windows 后台扫描、自己的下载上传，还是学校内部线路；可导出报告。右侧显示实时 Wi-Fi 状态和开局前建议。
- **体检与报告**：合并原网络诊断与网络工具；8 项体检、当前网络、延迟与回应、建议、Ping / DNS 小工具。原「网络测速」卡片（一直未配置）已移除。
- **设置**：校园网账号；一个「自动保持在线」总开关代替原来的开机自动登录 / 本机优先在线 / 快速复检，恢复时机、检测间隔放在高级选项里，改动即时生效；常规选项；关于。
- **高级工具**：原「下载与提速」（镜像测速与换源、多连接下载、DNS 设置）从设置页进入。

其他：

- Wi-Fi 信号通过 Windows 无线 API 读取（RSSI、信号质量、信道、热点 BSSID），不解析会随语言变化的 netsh 输出，不需要管理员权限。报告中热点只保留 BSSID 末两段。
- 桌面和开始菜单快捷方式改名为「稳连」；数据目录、账号和设置沿用原来的，不需要重新配置。
- 修复：「自动保持在线」关闭时选择的恢复时机会被重置，现在会保留到开启时生效。

验证：核心检查与 14 组界面测试全部按新界面更新并通过（含 412 项首页指标与窗口操作、334 项设置 / 体检 / 游戏模式布局、475 项状态区、88 项网络记录与分析含新增 Wi-Fi 判断、649 项缩放重绘、138 项窗口还原）。

## v0.8.8 游戏稳定性分析

校内稳定性监测新增证据分析：区分本机到网关波动、网关之后的校内服务方向波动，以及延迟突增与本机高下载/上传同时出现的情况。高流量只作为相关线索，不作为因果结论；高流量但延迟稳定时不会报网络故障。新增“查看占网程序”，打开 Windows 资源监视器供用户核对具体进程。

至少积累 5 个成功响应后才判断突增。流量线索要求下载不低于 2 MiB/s 或上传不低于 128 KiB/s，并达到最近最多 15 个流量样本中位数的 3 倍。报告写明阈值、当前判断及局限。仍只检测私网网关和学校认证服务器，不使用公网目标，不执行登录、重连、限速、QoS 或系统网络修改。

验证：84 项校内监测与分析、234 项页面操作、894 项缩放重绘、44 项交互、50 项呈现时序和 172 项窗口还原检查通过。版本号保持 v0.8.8；先前的窗口放大/还原屏幕闪烁仍未完成验收。

## 镜像服务器

点击“测试全部服务器”，逐个显示腾讯云、华为云、阿里云、中科大、清华 TUNA、网易的 MB/s、Mbps、采样耗时、有效字节和结果。每站单连接测两次，每次最多 4 MiB；整组最多约 48 MiB。HTTP 错误和限流不计为低速或成功。

所有站点使用同一个 Ubuntu 文件。这个排名只代表当前文件和线路，不代表某一家服务器永久最快，也不代表所有包管理器都同样快。可编辑测试文件的相对路径，失效时也可恢复默认值。

配置只修改相关源设置，保留其他配置；conda 通过已安装的 conda 命令修改。项目配置和环境变量可能优先于用户配置。如果软件源当前不可访问、存在无法可靠处理的复杂配置或缺少 conda，界面会显示原因，避免强行覆盖。

## 1—8 连接测速

填入文件直链，选择每档 8、16、32 MiB，点击“开始两轮对比”。第一轮按 1 至 8，第二轮按 8 至 1 测试。两轮都对每个连接数取相同总数据量，不把单条连接速度相加当作总速度。

界面显示两轮 Mbps、综合 MB/s、综合 Mbps 和状态。综合速度按两轮总字节除以两轮总耗时计算。速度在峰值 5% 以内时，优先建议较少连接。默认 16 MiB 整组最多约 256 MiB；8、32 MiB 分别约 128、512 MiB。小文件会减少采样量。

点击“将选中连接数用于下载”，随后仍可手动选择 1、4、8 或其他连接数。测速只反映当时结果，不能证明学校存在单连接限速，更不能保证突破套餐带宽。

## 多连接下载

输入 http / https 文件直链，选择保存位置和 1—8 连接，点击“开始下载”。可以填写发布者提供的 SHA256，下载后进行比对；未提供时仅显示本地摘要，不能据此证明文件来源真实性。

支持进度、平均速度、取消、打开所在文件夹。服务器不支持分段时自动使用单连接。每段检查 HTTP 206、Content-Range、字节数及可用的 ETag / 修改时间，再合并校验。遇到服务器限流则停止，不自动提高连接数。原有目标文件只有在整个下载成功后才会替换；失败或取消会清理本次临时文件。切换页面不会丢失当前任务和结果。

## DNS 设置

选择网卡，点击“测试 DNS 延迟”查看腾讯、阿里、华为和校内 DNS 的首地址解析 www.qq.com 的三次中位数。解析延迟不能代替下载带宽。

选择服务后点击“应用选中的 DNS”；也可选“自动获取”。Windows 会在应用或恢复时请求管理员权限。仅修改所选网卡 IPv4 DNS，IPv6 不变。首次修改按网卡保存原自动/静态模式及地址，点击“恢复此网卡原 DNS”还原。

外部 DNS 会为南华校内域名添加分流。已有相同设置会保留，已有冲突设置会停止。恢复只删除助手自己创建的规则。若先前应用过外部 DNS，切到自动获取仍保留校内分流；使用“恢复此网卡原 DNS”撤销助手管理的分流。

有代理或虚拟网卡时，测速可能反映代理路径；代理也可能接管 DNS。界面会在识别到常见代理网卡时提示，不会自动关闭代理或禁用网卡。
